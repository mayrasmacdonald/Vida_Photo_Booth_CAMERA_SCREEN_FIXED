# Vida Photo Booth CANVA EXACT

Dit is de schone implementatie waarbij het goedgekeurde artwork rechtstreeks als vaste afbeelding wordt gebruikt.

- Startscherm: exact artwork als PNG, alleen de knopzone is interactief.
- Resultaatscherm: exact artwork als PNG-overlay, de gemaakte foto wordt alleen in het transparante fotovak geplaatst.
- Opslaan en delen maken een afgewerkte JPG op basis van het fotovormgegeven sjabloon.
- Geen externe libraries of packages nodig.

## Starten op Mac
Open Terminal in `src` en gebruik:

`ruby -run -e httpd . -p 8766`

Open daarna in Safari:

`http://localhost:8766`
